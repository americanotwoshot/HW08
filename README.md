## 내일배움캠프 HW08
: 게임 루프 및 UI 재설계하기 

### 추가한 아이템
- SlowingItem : 이동속도 50% 감소
- ReverseControlItem : 방향키 반대로 입력 처리
- BlindItem : 시야 제한
- FastItem : 이동속도 50% 증가

### 웨이브별 변화
- Wave1 : 기존 로직 그대로 (40개의 아이템 생성)
- Wave2 : 체력을 감소시키는 스파이크 장애물 생성 (15개의 아이템 추가 생성)
- Wave3 : 생성되어 있는 MineItem을 1초당 하나씩 10초동안 임의로 발동 (20개의 아이템 추가 생성)

### 추가 구현 사항
- Level, Wave 시작 시 위젯 애니메이션 추가
- 아이템 별로 버프 구현 및 버프 UI 생성
- MineItem 활성화 시 구분이 되지 않아, 활성화 시에 더 붉게 발광하게 구현
- 레벨 별로 생성하는 아이템 구분(레벨 1에는 FastItem만 생성, 레벨 2,3에는 디버프 아이템 모두 생성)
